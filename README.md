# Order Management Dashboard – Operational Performance Analysis

## Overview
This project analyzes order fulfillment performance using the Brazilian Olist e-commerce dataset. It focuses on identifying delivery delays, regional inefficiencies, and operational bottlenecks.

## Tools Used
- Tableau
- Excel

## Key Insights
- Delivery performance improved over time
- Peak demand periods increase delays
- Regional disparities affect delivery efficiency

## Recommendations
- Optimize logistics in high-delay regions
- Improve order processing efficiency
- Scale operations during peak periods
